# miti99

Source code of my personal blog at [miti99.com](https://miti99.com), built with [Hugo](https://gohugo.io) and the [Stack](https://github.com/CaiJimmy/hugo-theme-stack) theme.

## Quick start

```bash
git submodule update --init --recursive
hugo server
```
